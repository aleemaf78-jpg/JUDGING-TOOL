# Hackathon Judging Tool

A web-based judging dashboard designed to simplify hackathon project evaluation.

## Features
- 40 team slots
- Judge score entry
- Five evaluation criteria
- Automatic score calculation
- Automatic leaderboard ranking
- CSV export

## Technologies Used
- HTML
- CSS
- JavaScript
- LocalStorage

## How to Run
1. Download the project.
2. Open index.html in Google Chrome.
3. Select a team.
4. Enter judge details and scores.
5. Save the evaluation.

## Purpose
To make hackathon judging organized, transparent and efficient.
